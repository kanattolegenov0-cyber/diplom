# Тексеру нәтижелері

Бұл нұсқа Linux бұлт ортасында Python 3.12 және жүйелік Chromium арқылы тексерілді.

- `.venv/bin/python -m pytest -q`: **502 тест өтті**. Музыка пәрмендері, дыбыс деңгейі, күнделік, апталық тапсырмалар, еске салулар, API, баптаулар және iPhone дыбыс жүктемесінің шектеулері тексерілді. Екі ескерту Python 3.13-те жойылатын `aifc` пен `audioop` модульдеріне қатысты.
- `node --check app/static/app.js`, Python модульдерін компиляциялау және `pip check` өтті.
- `AYAN_DATA_DIR=/tmp/ayan-check-removal .venv/bin/python desktop.py --check`: жергілікті сервер ашылып, интерфейс жүктеліп, процесс дұрыс тоқтады.
- Нақты Chromium-дағы оқшауланған интерфейс сынағында аниме мен браузер мәзірлері жоқ екені, музыка пәрменінің жауабы дауысталмағаны және микрофоннан берілген «дауысын көтер» пәрмені ойнатқышты 60%-дан 70%-ға өзгерткені тексерілді. JavaScript қатесі болған жоқ. Бұл сынақта дауыс тану, YouTube плеері және API жауаптары алмастырылды.
- Жойылған аниме және сайт басқару API жолдары 404 қайтаратыны тексерілді. Көмекшінің әрекеттер тізімінде бұл пәрмендер жоқ.
- iPhone өлшемімен Chromium тексеруінде орнату нұсқауы, микрофоннан 20 секундқа дейін жазу жолы және дауыс жазбасын жібергеннен кейінгі пәрмен орындалуы тексерілді. Мұнда нақты iPhone микрофоны мен Safari дыбыс кодегі алмастырылды.
- Серверге арналған Docker бейнесі жиналды; контейнердегі `/api/health` және PWA manifest HTTP арқылы ашылды. Кері прокси жіберген HTTPS origin қабылданып, бөгде Host қабылданбады. Docker Compose конфигурациясы мен Caddy HTTPS/құпиясөз конфигурациясы тексерілді. Қоғамдық домендегі HTTPS іске қосылған жоқ.

Бұл ортада нақты Windows/iPhone микрофоны, iPhone Safari орнатуы, WebView2 терезесі, YouTube/SoundCloud дыбысы және дайын `.exe` іске қосылған жоқ. iPhone нұсқасына жеке HTTPS домен мен сервер қажет. Windows-та жаңартылған қолданбаны ашып, өз микрофоныңызбен пәрмен беріп және нақты әннің дыбысын тексеріңіз. GitHub ZIP архивінде бастапқы код бар; Windows-та оны `start-windows.bat` арқылы іске қосуға болады.

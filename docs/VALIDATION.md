# Тексеру нәтижелері

Жоба Linux бұлт ортасында Python 3.12 және жүйелік Chromium 154 арқылы тексерілді.

- `python -m pytest -q`: **211 тест өтті**. Командалар, SQLite сақтау, API, URL/DNS шектеулері, модель жоспарларын тексеру, баптаулардың сақталуы, кілттердің API жауабына шықпауы және дауыс провайдерлерінің қателері тексерілді. Микрофонның дайындық күйлері, қатар жазуды бұғаттау және тыныш калибровкадан кейін нақты SpeechRecognition детекторімен жергілікті PCM сигналын қабылдау да тексерілді. Бұл PCM сынағы микрофон құрылғысы мен Google желісін қолданбайды. Starlette/httpx, audioop және aifc үшін 3 deprecation ескертуі бар; тесттер өтті.
- `node --check app/static/app.js`, Python модульдерін компиляциялау және `pip check` өтті.
- `desktop.py --check`: сервер loopback адресінде ашылды, интерфейс HTTP 200 қайтарды, сервер дұрыс тоқтады.
- Нақты Chromium интерфейсінде күнделікке командамен жазу, қайта жүктегенде сақталуы, еске салудың уақыты келгенде көрсетілуі және орындалуын белгілеу тексерілді.
- Басқарылатын Chromium `http://deb.debian.org/debian/` бетін ашып, суретін қайтарды. `README` сілтемесін басу пайдаланушы растағаннан кейін орындалды; бас тартқанда бет өзгермеді. Мәтін өрісін толтыру мен батырма басу бөлек бақыланатын HTML сынағында нақты Chromium арқылы тексерілді.
- YouTube сілтемесінен бейне ID алу нақты API арқылы өтті. Алғашқы әнді автоматты таңдау, пауза/дыбыс командалары және ойнатқыш қатесінен кейін қайта іске қосу YouTube API сынақ алмастырғышымен тексерілді. Бұл нақты дыбыс ойнатылғанын растамайды.
- Интерфейс тексерулерінде JavaScript қателері табылмады; 390 px экранда көлденең жылжу жоқ. Күнделік HTML мәтінін қауіпсіз қарапайым мәтін ретінде көрсетеді.
- Микрофон интерфейсі API алмастырғыштарымен нақты Chromium ішінде тексерілді: калибровка → дайын микрофон → сөзді тану, «Дауыс естілмеді» қатесінен кейін қалыпты күйге оралу, кешіккен жауапты елемеу және жазу аяқталғанда күй сұрауын тоқтату. Микрофон дайын деген белгі серверден келген күйге негізделеді.

## GPT және жаңа дауыс провайдерлері

Еркін сұраулар үшін әдепкі модель — `gpt-4.1-mini`. Қолданба модель ұсынған әрекеттерді қолжетімді құралдармен шектейді және бір сұрауда 6 әрекетке дейін ретімен орындайды; браузер батырмасын басу пайдаланушы растауын талап етеді. Бұл кез келген тапсырманы толық түсіну немесе орындау кепілдігі емес.

Осы ортада OpenAI API кілті берілмеген. Нақты ақылы GPT сұрауы орындалған жоқ; модельді алмастырғышпен тексеру нақты OpenAI аккаунтының қолжетімділігін немесе оның жауабының сапасын растамайды.

Жаңартылған интерфейс нақты Chromium мен жергілікті API/SQLite арқылы бірге тексерілді: баптауларды сақтау, кілтті браузер жадына сақтамау, ән атауын resolver арқылы өткізіп автоматты таңдау, екі қадамды күнделік/еске салу жоспары, басудан бас тартқанда кейінгі қадамдарды тоқтату және қате іздеуден кейін жазба қоспау өтті. Модель мен YouTube осы сынақта алмастырылды. Дауыс endpoint-інен келген жергілікті сынақ MP3 дыбысын Chromium декодтап, ойнатуды аяқтады; бұл қазақша провайдердің нақты дауысы емес, арнайы жасалған қысқа дыбыс сигналы. 390 px интерфейсінде көлденең жылжу және JavaScript қателері табылмады.

Әдепкі қазақша дауыс — Microsoft Edge онлайн сервисіндегі `kk-KZ-DauletNeural`; `kk-KZ-AigulNeural` таңдауға болады. ElevenLabs үшін пайдаланушының API кілті және дайын қолжетімді voice ID қажет. AniLibria актерінің дайын TTS моделі немесе voice ID берілмеген: нақты актер дауысы қосылды немесе тексерілді деп есептелмейді. ElevenLabs моделінің қазақша қолдауын және таңдалған дауыстың айтылуын провайдермен бөлек тексеру керек.

Нақты Edge қазақша дауыстау сынағы осы бұлттағы прокси шектеуінен `ClientHttpProxyError` қатесімен тоқтады: MP3 алынған жоқ, пайдаланушыға қазақша қате көрсетілді. Қажетті домен — `speech.platform.bing.com`. ElevenLabs ресми құжаттары мен ашық модельдер сұрауы да `403` қайтарды; ақылы дауыстау сұрауы орындалған жоқ. Қолданба ElevenLabs моделінің тіл қолдауын синтезге дейін аутентификацияланған ресми модельдер тізімінен тексереді, сондықтан қазақша қолдау бұл құжатта алдын ала расталған деп көрсетілмейді.

PyInstaller сценарийі жаңа `edge_tts`, `aiohttp`, `certifi` және `httpx` модульдері мен ресурстарын жинауға толықтырылды. Бұл өзгеріс дайын Windows `.exe` сынағын алмастырмайды; оны нақты Windows-та жинап, **Баптаулар → Дауысты тексеру** және GPT сұрауы арқылы тексеру қажет.

Орта черновигіне `api.openai.com`, `speech.platform.bing.com`, `api.elevenlabs.io` домендері, жаңартылған `start_skill` және жеке пайдаланушының екі қосымша API кілтінің атауы сақталды. Нақты кілт мәндері қосылған жоқ. Бұлтта қолдану үшін өзгерістерді орта баптауларынан қарап, сақтап, ортаны жариялау қажет; черновикті сақтау іске қосылған машинаның желісін өздігінен өзгертпейді. Windows қолданбасындағы кілттер осы бұлт баптауынан бөлек, қолданбаның **Баптаулар** бөлімінде енгізіледі.

## Осы ортадағы шектеулер

YouTube пен Playwright жүктеу домендері бастапқы желі тізімінде жоқ: сұраулар `403 Domain forbidden` қайтарды. Chromium жүктеу орнына бұрыннан орнатылған жүйелік браузер қолданылды. `install_script`, `start_skill` және YouTube, Google Speech, Chromium жүктеу, Wikipedia үшін қажетті домендер орта баптауының черновигіне сақталды. Параметрлерді қарап, сақтап, ортаны жариялағаннан кейін желі қолжетімділігін қайта тексеру қажет. Черновикті сақтау ағымдағы желіге автоматты түрде рұқсат бермейді.

Бұлтта домендер HTTPS проксиі арқылы шешіледі, сондықтан браузер тексеруінде `AYAN_PROXY_DNS=1` қолданылды. Бұл режим атауларды шешу мен желі бағыттарын шектеуді сенімді проксиге тапсырады. Windows әдепкі режимінде жергілікті DNS тексеріледі.

Бұл Chromium көшірмесінде прокси арқылы HTTPS бетіне кіргенде `ERR_CERT_AUTHORITY_INVALID` байқалды. Платформаның CA сертификаттары бұрынғы NSS қоймасында бар; қазіргі Chromium пайдаланатын сенім қоймасымен сәйкестендіру қажет. Оны жаңа жолға байланыстыруға арналған sandbox escalation орындау көлігінің үзілуіне байланысты орындалмады. TLS тексеруі өшірілген жоқ. Нақты браузердің HTTP әрекеттері өтті, бірақ осы бұлттағы HTTPS әрекеттері расталмаған.

Windows native терезесі, PowerShell сценарийлері, микрофоннан нақты дауыс тану, жүйелік дауыс және дайын `.exe` Linux ортасында тексерілген жоқ. Оларды Windows компьютерінде іске қосып тексеру қажет. Қазір берілген архив — бастапқы код; дайын Windows бинарлық файлы емес.

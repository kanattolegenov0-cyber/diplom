# Аян үшін тегін бұлт сервері

Егер компьютер үнемі қосулы тұрмаса, iPhone-дағы Аянға интернеттегі сервер керек. Қазіргі жоба Python серверін, Ollama моделін және сақталатын күнделік пен тапсырмаларды пайдаланады. **GitHub Pages немесе Safari-ге белгіше қосу бұл сервердің орнын баспайды.**

## Ұсынылатын жол: Oracle Cloud Always Free

[Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/) ішіндегі **Ampere A1 Flex** сервері осы жобаға сәйкес келуі мүмкін: Always Free лимиті әдетте барлығы **4 OCPU және 24 ГБ RAM**, сондай-ақ **200 ГБ block storage** береді. Бұл лимит жеке тіркелгіге ортақ; оны басқа серверлер де пайдаланып жатса, Аянға азырақ ресурс қалады. Біздің `ollama/ollama` контейнерінің Linux ARM64 бейнесі бар, ал Аянның Python сервері де ARM64-та жұмыс істей алады. `qwen2.5:3b` моделіне кемінде 8 ГБ RAM бөліңіз; 12–24 ГБ жақсырақ.

Бұл қызметке тіркелу үшін төлем картасы сұралуы мүмкін. **Always Free** белгісі бар пішінді ғана таңдаңыз, ақылы жазылымға өтпеңіз және ресурстарды тегін лимиттен асырмаңыз. Тегін сервер орны таңдаған аймақта болмауы мүмкін; аймақ пен пішін қолжетімділігін Oracle тіркелгісінде тексеру қажет. Тариф пен қолжетімділік өзгеруі мүмкін, сондықтан серверді жасар алдында [ресми Always Free шарттарын](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier.htm) қайта оқыңыз. Қызмет бос тұрған тегін инстанстарды қайтарып ала алады; күнделік пен тапсырмалардың көшірмесін бөлек сақтаңыз.

## Қадамдар

1. [Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/) бетінде өз тіркелгіңізді ашыңыз. Төлем картасының мәліметін, парольді немесе SSH жеке кілтін басқа адамға жібермеңіз.
2. **Compute → Instances → Create instance** арқылы Ubuntu 24.04 ARM64 серверін жасаңыз. Пішін: **VM.Standard.A1.Flex**, тегін белгісін тексеріңіз; мүмкіндік болса **4 OCPU / 24 ГБ RAM** таңдаңыз. Boot volume мен басқа block volume-дардың жалпы көлемі тегін лимит ішінде қалсын. SSH кілт жұбын сақтаңыз, серверге сыртқы IPv4 мекенжайын беріңіз.
3. Oracle желісінде TCP **80** және **443** порттарына кіріс ережесін қосыңыз. TCP **22** портын мүмкін болса тек өз IP мекенжайыңызға ашыңыз. Ubuntu-да қосымша firewall жұмыс істесе, оның ережелерін де сәйкестендіріңіз. **8000** және **11434** порттарын интернетке ашпаңыз: Compose оларды ішкі желіде ұстайды.
4. Windows PowerShell-де серверге SSH арқылы кіріңіз (кілт жолы мен IP-ді өзіңіздікіне ауыстырыңыз):

   ```powershell
   ssh -i "C:\path\to\your-key.key" ubuntu@SERVER_IP
   ```

5. Серверге [Docker Engine және Compose plugin](https://docs.docker.com/engine/install/ubuntu/) орнатыңыз, содан кейін репозиторийді алыңыз:

   ```bash
   git clone https://github.com/kanattolegenov0-cyber/diplom.git
   cd diplom
   docker compose version
   ```

   `docker compose` жұмыс істемесе, Docker орнату нұсқаулығындағы **Compose plugin** қадамын орындаңыз. Docker пәрменіне рұқсат жетпесе, сол пәрмендерді `sudo docker compose ...` түрінде орындаңыз.

6. [DuckDNS](https://www.duckdns.org/) арқылы тегін `атау.duckdns.org` атауын ашып, оны сервердің сыртқы IPv4 мекенжайына бағыттаңыз. IP ауысса, DuckDNS жазбасын жаңартыңыз. [iPhone орнату нұсқаулығындағы](IOS.md#серверді-дайындау) `.env`, құпиясөз хэші, Docker Compose және Ollama қадамдарын орындаңыз. Құпиясөздің хэшін ғана `.env` файлына жазыңыз; файлды GitHub-қа салмаңыз.
7. `https://атау.duckdns.org` Safari-де ашылғанын және Аян құпиясөзді сұрайтынын тексеріңіз. Содан кейін **Бөлісу → Басты экранға қосу** басыңыз.

`VM.Standard.A1.Flex` қолжетімсіз болса, тегін орын пайда болуын күтуге немесе басқа аймақты тексеруге болады. Көптеген тегін веб-хостинг жоспарларында Ollama үшін RAM, тұрақты диск немесе тәулік бойғы жұмыс жетпейді. Мұндай жоспарға көшіргенде Аянның қазіргі мүмкіндіктері толық сақталмайды.

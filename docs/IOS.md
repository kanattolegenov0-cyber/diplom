# Аянды iPhone-ға орнату

Аянның iPhone нұсқасы — Safari арқылы басты экранға қосылатын веб-қолданба. Python, WebView2 немесе Windows орнатқышы телефонға қажет емес. Күнделік, апталық тапсырмалар, плейлист пен Ollama моделі жеке серверде сақталады; телефон сол серверге HTTPS арқылы қосылады. Компьютеріңіз өшірулі болса да жұмыс істеуі үшін сервер тәулік бойы қосулы болуы керек. Бұл хостинг пен домен шығынын талап етуі мүмкін.

## Серверді дайындау

DNS атауы және кемінде 8 ГБ RAM бар Linux сервер керек. Өз доменіңіз болмаса, [DuckDNS](https://www.duckdns.org/) қызметінен тегін `атыңыз.duckdns.org` қосалқы доменін ашып, оны сервердің сыртқы IP мекенжайына бағыттай аласыз. IP өзгеріп тұрса, DuckDNS жаңарту клиентін орнату қажет. Серверде Docker мен Docker Compose орнатыңыз. 80 және 443 порттарын ашыңыз: олар Caddy-ге HTTPS сертификатын алуға қажет. Үй сервері болса, маршрутизаторда порттарды сол серверге бағыттау қажет; сыртқы IP мүлдем болмаса, алдымен басқа қауіпсіз қосылу жолын таңдау керек. Жеке сервердің құпиясөзін ешкіммен бөліспеңіз.

Жоба қалтасында:

```bash
cp deploy/.env.example deploy/.env
docker run --rm -it caddy:2.10 caddy hash-password
```

Соңғы пәрмен ұсынған жерде ұзын жеке құпиясөзді енгізіңіз. Берілген bcrypt хэшін `deploy/.env` ішіндегі `AYAN_PASSWORD_HASH` мәніне қойып, түгелін бір тырнақшаға алыңыз: `AYAN_PASSWORD_HASH='$2a$...'`. Осылай `$` таңбалары сақталады. `AYAN_DOMAIN` мәніне өз доменіңізді жазыңыз. `.env` GitHub-қа жүктелмейді.

```bash
docker compose --env-file deploy/.env -f deploy/compose.yaml up -d --build
docker compose --env-file deploy/.env -f deploy/compose.yaml exec ollama ollama pull qwen2.5:3b
```

Сервердің доменін Safari-де ашыңыз. `ayan` пайдаланушысы мен өзіңіз таңдаған құпиясөзді енгізіңіз. Сосын **Бөлісу → Басты экранға қосу** басыңыз. Егер Safari қайта құпиясөз сұраса, сол деректерді енгізіңіз. Сөйлесу үшін **Баптаулар → AI қызметі → Ollama** таңдалғанын және модель дайын екенін тексеріңіз.

Музыка YouTube немесе SoundCloud ресми плеерінде ойналады. iPhone автоматты ойнатуды бұғаттаса, әннің **Ойнату** батырмасын басыңыз. iPhone микрофонын басып, пәрменді айтыңыз; 20 секундтан кейін жазба тоқтайды немесе батырманы қайта басып тоқтатасыз. Жазба жеке серверге жіберіледі. Серверде Whisper орнатылмаса, сөзді тану үшін Google сервисі пайдаланылады.

## Шектеулер

- «Аян» деп үздіксіз шақыру iPhone-да, әсіресе экран құлыптаулы не қолданба жабық кезде, жұмыс істемейді. Пәрмен үшін микрофон батырмасын басыңыз.
- Еске салғыштар қолданба ашық тұрғанда көрінеді. iPhone-ға фондық push-хабарламалар бұл нұсқада қосылмаған.
- Басты экрандағы белгіше қолданбаны ашуға мүмкіндік береді; сөйлесу, музыка іздеу және деректерді синхрондау үшін сервер мен интернет қажет. Офлайнда тек интерфейстің соңғы көшірмесі ашылуы мүмкін.
- Бұлттағы Ollama моделі сервердің RAM/CPU ресурсын пайдаланады. Телефонда модель жүктелмейді.

Windows-тағы бұрынғы күнделік пен тапсырмалар iPhone серверіне автоматты көшірілмейді. Оларды кейін бөлек көшіру қажет; Windows-та сақталған құпия кілттерді серверге көшірмеңіз.

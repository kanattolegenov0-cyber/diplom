# Аян / AYAN

Аян — қазақша интерфейсі мен қазақша нейрондық дауысы бар жеке көмекші. Windows жүйесінде бөлек терезе ретінде жұмыс істейді; команданы микрофонмен немесе мәтінмен беруге болады. Жергілікті шақыру режимін қоссаңыз, **«Аян»** деп шақырғанда пәрменді тыңдауға ауысады. Еркін сұхбат үшін әдепкіде компьютердегі тегін **Ollama** моделі қолданылады; OpenAI API балама ретінде қалады. Күнделік, еске салулар және тыңдалған әндерден жиналатын плейлист компьютердегі SQLite базасында сақталады.

## GitHub-тан жүктеп, іске қосу

1. [GitHub жобасын](https://github.com/kanattolegenov0-cyber/diplom) ашып, **Code → Download ZIP** басыңыз. Немесе [main тармағының ZIP архивін](https://github.com/kanattolegenov0-cyber/diplom/archive/refs/heads/main.zip) жүктеңіз. Репозиторий жеке болса, өз GitHub аккаунтыңызбен кіріңіз.
2. Архивті **Extract All / Барлығын шығару** арқылы ашыңыз. Жаңартып жатсаңыз, жаңа ZIP-ті бөлек қалтаға шығарып, сол көшірмені іске қосыңыз. `diplom-main` қалтасының ішіндегі файлдармен жұмыс істеңіз; BAT файлын архивтің ішінен іске қоспаңыз.
3. [Python 3.12, 64-bit](https://www.python.org/downloads/windows/) орнатыңыз. Орнату кезінде **Add python.exe to PATH** белгісін қосыңыз.
4. [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section) орнатыңыз, егер ол компьютерде болмаса.
5. Жоба қалтасындағы **`start-windows.bat` файлын екі рет басыңыз**. Интернет қосулы болсын: алғашқы іске қосу тәуелділіктер мен Chromium браузерін орнатады. Орнату аяқталғанша терезені жаппаңыз.
6. **Баптаулар → Көмекшінің дауысы** бөлімінде Microsoft Edge провайдерін және **Дәулет** немесе **Айгүл** дауысын таңдаңыз. **Баптауларды сақтау**, содан кейін **Дауысты тексеру** батырмасын басыңыз. Қазақша дауысқа API кілті керек емес, интернет керек.
7. Еркін сұхбатты тегін қосу үшін [Ollama-ны орнатыңыз](https://ollama.com/download/windows), кейін **`setup-ollama.bat`** файлын бөлек іске қосып, модельдің жүктелуін күтіңіз. **Баптаулар → Ақылды көмекші → AI қызметі** бөлімінде **Ollama · жергілікті, тегін**, модель ретінде `qwen2.5:3b` таңдап сақтаңыз. Толық қадамдар төменде; OpenAI кілті қажет емес.
8. Микрофонға рұқсат беріңіз. Мәтінмен `Күнделікке жаз: Аянды іске қостым` командасын тексеріңіз; кейін микрофон батырмасын басып, **«Айтыңыз»** деген белгі шыққанда сөйлеңіз.
9. Микрофон батырмасын баспай шақыру үшін **«„Аян“ деп шақыру» → Шақыру моделін орнату** таңдаңыз. Әдепкіде модель орнатылған соң шақыру қосылады; өшірулі болса, **Шақыруды қосу** басыңыз. «Аян» деп айтыңыз, **«Айтыңыз»** белгісін күтіп, содан кейін пәрмен беріңіз. Тоқтату үшін **Шақыруды тоқтату** басыңыз.

**Лицензиялық активация кілті қажет емес.** `start-windows.bat` жобаның `.venv` ортасын өзі жасайды және оның Python көшірмесін қолданады; ортаны қолмен активтеу қажет емес.

Ортаны өзіңіз қолмен активтегіңіз келсе, жоба қалтасында **Command Prompt (CMD)** ашып орындаңыз:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements-desktop.txt
python desktop.py
```

CMD жолының басында `(.venv)` белгісі шықса, орта активтелді. Бұл командалар CMD үшін берілген; PowerShell-де негізгі `start-windows.bat` жолын пайдаланыңыз.

GitHub ZIP архивінде бастапқы код беріледі. Windows-та дайын `.exe` жасау үшін төмендегі жинау нұсқаулығын қараңыз.

## Мүмкіндіктер

- Қазақша және орысша командаларды тану, мәтіндік жауап, Microsoft-тың қазақша **Дәулет** және **Айгүл** нейрондық дауыстарымен оқу.
- Пайдаланушы қосқанда «Аян» шақыру сөзін жергілікті Vosk моделімен үнемі тыңдау және шақырудан кейін қысқа пәрменді қабылдау.
- Жергілікті Ollama моделімен API кілтінсіз сөйлесу; қалауыңызша OpenAI API пайдалану. Модель бір сұрауда қолжетімді 6 әрекетке дейінгі жоспар құра алады.
- YouTube және SoundCloud арқылы ән іздеу, ойнату, кідірту, жалғастыру және дыбысын реттеу; YouTube қолжетімсіз болса, SoundCloud-қа автоматты ауысу.
- Аниме үшін Аянның ішіндегі бөлек бет: AnimeGo-дан атаумен іздеу, бар болса маусым мен серия сілтемесін таңдау және бейнені сол бетте көрсету.
- Нақты тыңдалған әндерден жиілікке қарай реттелетін жеке плейлист жинау.
- Сайт ашу, браузер бетінің суретін көру, өріске мәтін енгізу, батырма басу, бетті жылжыту және артқа қайту. Батырманы басар алдында пайдаланушы әрекетті растайды.
- Күнделікке жазба қосу, жазбаларды көру және жою.
- 1 секундтан 30 күнге дейінгі еске салуларды сақтау және орындалғанын белгілеу.

Белгілі командалар жылдам ережелер арқылы орындалады; түсіндірмесі еркін сұрауларды таңдалған AI моделі өңдейді. Модель тек қолданба қолдайтын музыка, аниме іздеу, браузер, күнделік, еске салу және жауап беру әрекеттерін ұсына алады. Батырма басу пайдаланушының растауын талап етеді. Кез келген тапсырманы толық түсініп, міндетті түрде орындайтынына кепілдік жоқ; еркін код орындау мүмкіндігі қосылмаған. Браузерді басқару ашық HTTP/HTTPS сайттарына арналған.

## Ollama: тегін жергілікті сұхбат

1. [Ollama-ның ресми Windows орнатқышын](https://ollama.com/download/windows) жүктеп орнатыңыз, кейін Windows Start мәзірінен **Ollama** ашыңыз.
2. Жоба қалтасындағы **`setup-ollama.bat`** файлын екі рет басыңыз немесе PowerShell-де орындаңыз:

```powershell
.\setup-ollama.bat
```

Көмекші бар Ollama бағдарламасын табады, қажет болса оның `127.0.0.1:11434` жергілікті серверін іске қосады және `ollama pull qwen2.5:3b` орындайды. Модельді жүктеуді осы көмекшіні іске қосу арқылы өзіңіз бастайсыз; `start-windows.bat` модельді автоматты жүктемейді. Ollama табылмаса, көмекші ресми орнату сілтемесін көрсетеді. Ол қашықтағы орнату скрипттерін орындамайды және әкімші құқығын сұрамайды.

3. Аянда **Баптаулар → Ақылды көмекші** ашыңыз. **AI арқылы сөйлесу және күрделі пәрмендер** қосулы болсын; **AI қызметі → Ollama · жергілікті, тегін**, **Ollama моделі → `qwen2.5:3b`** таңдаңыз. **Баптауларды сақтау**, содан кейін **Қайта тексеру** басыңыз.
4. Мәтінмен сұрақ беріңіз. Сөйлесу үшін Ollama жұмыс істеп тұруы керек; модельді бірінші ашу мен алғашқы жауап әдеттегіден ұзағырақ болуы мүмкін.

Модельді алғашқы жүктеуге интернет пен бос диск орны керек. Бастауға **8 ГБ RAM немесе одан көбі ұсынылады**; бұл әр компьютерде бірдей жылдамдыққа кепілдік бермейді. Жады аз компьютерде кіші модельді таңдауға болады:

```powershell
.\setup-ollama.bat -Model qwen2.5:1.5b
```

Содан кейін баптауда модельді де `qwen2.5:1.5b` деп өзгертіп сақтаңыз. Кіші модельдің жауап сапасы, соның ішінде қазақша түсінуі әлсіздеу болуы мүмкін. Жергілікті шағын модельден GPT деңгейіндегі қазақша сапаға кепілдік жоқ. Модельдің ресми беттері: [qwen2.5:3b](https://ollama.com/library/qwen2.5:3b), [qwen2.5:1.5b](https://ollama.com/library/qwen2.5:1.5b).

Модель жүктелгеннен кейін **мәтіндік сұхбат жергілікті, API кілтінсіз және интернетсіз** жұмыс істейді. YouTube, сыртқы сайттар, Microsoft Edge дауыстауы және Google Speech арқылы пәрмен тану интернетті пайдалануды жалғастырады. Ollama-ны таңдау осы сервистерді офлайнға айналдырмайды. Ollama модельдерін өз қоймасында сақтайды; оларды Аянның деректер қалтасына көшіру қажет емес.

## OpenAI: қосымша ақылы балама

1. [OpenAI API кілттері](https://platform.openai.com/api-keys) бетінде өз аккаунтыңызбен кілт жасаңыз. OpenAI API аккаунтындағы төлем немесе баланс бапталған болуы керек: **ChatGPT жазылымы OpenAI API төлемін қамтымайды**.
2. Аяндағы **Баптаулар → Ақылды көмекші → AI қызметі** бөлімінде **OpenAI · ақылы API** таңдаңыз. **OpenAI API кілті** өрісіне кілтті енгізіп сақтаңыз. Кілтті чатқа, README файлына немесе GitHub-қа жібермеңіз.
3. **AI арқылы сөйлесу және күрделі пәрмендер** қосулы болсын. Әдепкі OpenAI моделі — `gpt-4.1-mini`; OpenAI моделінің өрісінде аккаунтыңызға қолжетімді өзге үйлесімді модельді көрсетуге болады.
4. Қазақша сұрақ немесе бірнеше әрекетті қамтитын пәрмен беріңіз. Әрекеттер қолданба қолдайтын құралдармен ғана орындалады; модель қатесі болса, интерфейс хабарлайды.

OpenAI API пайдалануы провайдер тарифіне сәйкес ақылы. Бұлт ортасында API кілті берілмеген, сондықтан ақылы нақты GPT сұрауы орындалып тексерілген жоқ. Қарапайым музыка, күнделік, еске салу және браузер командалары үшін GPT кілті міндетті емес.

Кілт қолданбадағы құпия өріске енгізіледі және Windows пайдаланушысының DPAPI қорғанысымен жергілікті сақталады. Кілт баптауларды қайта жүктегенде мәтін ретінде қайтарылмайды. Әзірлеу ортасында кілтті `AYAN_LLM_API_KEY` айнымалысы арқылы беруге болады; оның мәнін репозиторийге қоспаңыз.

## «Аян» деп микрофон батырмасынсыз шақыру

Шақыру сөзі **Vosk** арқылы компьютерде танылады. Оны пайдалану үшін толық шағын қазақша модель бір рет орнатылуы керек:

1. Аянды `start-windows.bat` арқылы іске қосып, Windows микрофон рұқсатын тексеріңіз.
2. **«„Аян“ деп шақыру» → Шақыру моделін орнату** басыңыз. Орнату интернеттен ресми `alphacephei.com` сайтындағы модельдер тізімін алып, тұрақты шағын қазақша модельді таңдайды. Модель атауы мен көлемі ресми метадеректен алынады; мұнда тексерілмеген нұсқа не көлем көрсетілмейді. Жүктеу бірнеше минутқа созылуы мүмкін.
3. Интерфейстегі шақыру күйін тексеріңіз. Әдепкіде орнатудан кейін қосылады; өшірулі болса, **Шақыруды қосу** басыңыз. **Баптаулар → „Аян“ деп шақыру** бөлімінде шақырудан кейінгі пәрмен тілін таңдауға болады.
4. Алдымен **«Аян»** деп айтыңыз. **«Айтыңыз»** белгісі шыққанша үнсіз күтіңіз, содан кейін пәрменді айтыңыз. Атын және пәрменді үзіліссіз бір сөйлеммен айту алғашқы сөздерді өткізіп жіберуі мүмкін.
5. Тыңдауды өшіру үшін **Шақыруды тоқтату** басыңыз немесе қолданбаны жабыңыз.

Шақыруды тыңдау кезінде микрофон дыбысы жергілікті модельде өңделеді. **Үздіксіз аудио бұлтқа жіберілмейді.** «Аян» танылғаннан кейінгі қысқа пәрмен ғана бұрынғы Google Speech жолымен мәтінге айналдырылады; осы кезеңде интернет керек. Қолмен микрофон батырмасын басу да қысқа пәрменді Google-ға жібереді. Vosk моделін алғашқы жүктеу — бөлек интернет әрекеті, ол микрофон аудиосын жібермейді.

Аян қолданбасы ашық тұруы керек. Терезені жабу процесті және тыңдауды тоқтатады; Windows фондық қызметі орнатылмайды. Шулы бөлмеде немесе микрофон дұрыс таңдалмаса, шақыру сөзі танылмауы мүмкін — Windows дыбыс кірісін және интерфейстегі күйді тексеріңіз.

Модель `%LOCALAPPDATA%\Ayan\wake-model` ішінде сақталады. Орнатқыш тек ресми HTTPS адресінен жүктейді, жарияланған MD5/SHA бақылау сомаларын тексереді және 200 МБ-тан үлкен архивті автоматты жүктемейді. Жүктеу не тексеру сәтсіз болса, модель дайын деп көрсетілмейді. Бұрыннан осы қалтадағы белгісіз файлдар өзгертілмейді.

Дайын жергілікті модельді пайдалансаңыз, `AYAN_WAKE_MODEL_PATH` айнымалысында оның ашылған қалтасын көрсетіңіз. Қалтада `am/final.mdl`, `conf/model.conf` және `graph` ішіндегі модель файлдары болуы керек; ZIP файлының жолын көрсетпеңіз. Ресми модельдер: [Vosk models](https://alphacephei.com/vosk/models).

## Қазақша дауыс және AniLibria дауыстары

Әдепкі провайдер — **Microsoft Edge** онлайн сөйлеу сервисі (`edge-tts`). Қазақша ер дауыс — **Дәулет / `kk-KZ-DauletNeural`**, әйел дауыс — **Айгүл / `kk-KZ-AigulNeural`**. Әдепкі мәнер — ұстамды ер дауыс; бұл фильмдегі Jarvis немесе нақты AniLibria актерінің дайын дауыс моделі емес. Өзгертулерді **Баптауларды сақтау** арқылы сақтап, **Дауысты тексеру** арқылы тыңдаңыз. API кілті қажет емес; онлайн сервистің қолжетімділігіне байланысты интернет керек.

**ElevenLabs** провайдері дайын рұқсат етілген немесе ортақ voice ID үшін қарастырылған: өз API кілтіңізді, аккаунтыңызға қолжетімді **voice ID** және үйлесімді модельді енгізіңіз. Әдепкі модель — `eleven_v3`. Қолданба аудио сұрамас бұрын провайдердің модельдер тізімінен таңдалған модельдің қазақша қолдауын тексереді; қолдау расталмаса, қате көрсетеді және **Edge** дауысын өзіңіз таңдауыңыз керек. Қызмет тарифін провайдерден тексеріңіз; қазақша айтылуын міндетті түрде **Дауысты тексеру** арқылы тыңдаңыз. AniLibria дубляж актерінің дайын TTS моделі немесе voice ID берілмеген, сондықтан осы нұсқада нақты актер дауысы қосылған жоқ. Кілттің өзі актер моделін жасамайды.

**Компьютер дауысы** таңдалса, браузерде қазақша жүйелік дауыс орнатылған болуы керек. Қазақша дауыс табылмаса, қолданба хабарлайды; қазақша мәтінді орысша дауыспен автоматты алмастырмайды.

## Windows: іске қосу

Бастапқы кодтан іске қосу үшін [Python 3.12, 64-bit](https://www.python.org/downloads/windows/) орнатыңыз. Native терезе үшін [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section) керек; Windows-та ол жиі алдын ала орнатылған болады.

Python орнатылғаннан кейін жоба қалтасындағы **`start-windows.bat` файлын екі рет басыңыз**. Немесе PowerShell-де орындаңыз:

```powershell
.\start-windows.bat
```

Скрипт `.venv` жасайды, нұсқалары бекітілген тәуелділіктерді орнатады және көмекшіні іске қосады; жаңартылған көшірмеде жаңа тәуелділіктерді де орнатады. Алғашқы іске қосқанда Playwright Chromium жүктеледі; кейін сол көшірме қолданылады. Бастапқы орнатуға интернет керек. BAT файлдары жоба ішіндегі PowerShell скриптін осы процесс үшін `ExecutionPolicy Bypass` арқылы ашады; Windows орындау саясатын тұрақты өзгертпейді. Қате болса, терезе хабарламаны оқу үшін ашық қалады.

Native терезе ашылмаса, кәдімгі браузер режимін пайдаланыңыз:

```powershell
.\start-windows.bat -Web
```

Бұл режимдегі серверді тоқтату үшін PowerShell-де `Ctrl+C` басыңыз. Микрофонға Windows параметрлерінен рұқсат беріңіз: **Settings → Privacy & security → Microphone → Let desktop apps access your microphone**.

## Windows: жеке қолданба жинау

Windows компьютерінде Python 3.12 орнатып, **`build-windows.bat` файлын екі рет басыңыз** немесе PowerShell-де орындаңыз:

```powershell
.\build-windows.bat
```

Нәтиже: `dist\Ayan\Ayan.exe`. Толық **`dist\Ayan` қалтасын**, оның ішінде `_internal` қалтасын бірге көшіріңіз. Бұл бір қалтадан іске қосылатын қолданба; оны қолданатын компьютерге Python орнату қажет емес. WebView2 Runtime қажет, ал басқарылатын Chromium жаңа компьютерде алғаш іске қосылғанда жүктеледі.

Жинау скрипті `Ayan.exe --check` арқылы браузер орнатылымы мен жергілікті бетті тексереді. Windows терезесін, микрофонды және дыбысты нақты Windows компьютерінде тексеру керек: Linux бұлт ортасы Windows `.exe` жұмысын растай алмайды.

Chromium жүктеуді терезені ашпай бөлек орындауға болады:

```powershell
Start-Process .\dist\Ayan\Ayan.exe -ArgumentList "--install-browser" -Wait
```

Еркін мәтін ән атауы не пәрмен екені анық болмаса, AI моделі қосылғанда сұрауды түсіндіруге көмектеседі немесе нақтылау сұрайды. Сайт өрісінің немесе батырмасының атауы сол беттегі атаумен сәйкес болуы керек. Команда орындалмаса, интерфейстегі браузер басқару өрістерін пайдаланыңыз.

## Дауыс, музыка және еске салулар

Қолмен басқару режимінде микрофон батырманы басқанда тыңдайды. «Аян» шақыру режимі қосулы болса, микрофон жергілікті шақыру моделіне үнемі ашық болады; шақырудан кейінгі пәрмен таңдалған қызметпен танылады. Whisper орнатылса, дыбыс компьютерде өңделеді; Google таңдалса, қысқа жазба Google Speech қызметіне HTTPS арқылы жіберіледі. Автоматты режимде орнатылған Whisper қолданылады, модель жоқ болса Google қолданылады. Whisper қатесі кезінде дыбыс Google-ға автоматты жіберілмейді. Whisper «Аян» сөзімен бірге айтылған пәрменді де жадтағы қысқа жазбадан қайта таниды; фондық дыбыс файлға сақталмайды және Google-ға жіберілмейді. Браузер режимінің сөйлеуді тану қызметі браузерге байланысты. Ollama таңдалса, сұхбат жергілікті модельде өңделеді. OpenAI таңдалған сұрауда оның мәтіні мен сөйлесудің соңғы 8 хабары OpenAI сервисіне жіберіледі. Онлайн дауыстау кезінде жауап мәтіні таңдалған дауыс сервисіне жіберіледі. Құпия ақпаратты жібермеңіз; мәтіндік командалар да жұмыс істейді. Microsoft пен ElevenLabs дауыстары онлайн жасалады, компьютер дауысы орнатылған дауыстарға байланысты.

Микрофон батырмасынан кейін бағдарлама алдымен шамамен 1 секунд фондық шуды өлшейді. Осы кезде үнсіз күтіңіз. **«Айтыңыз, тыңдап тұрмын…»** шыққанда команда беріңіз. Дауыс қабылданғанда экран **«Дауыс қабылданды, мәтінге айналдырып жатырмын…»** деп өзгереді.

Музыка бетінде **Музыка көзі → Автоматты · YouTube → SoundCloud** таңдаңыз. YouTube іздеуі немесе бейне ойнатуы сәтсіз болса, Аян сол сұрауды SoundCloud-тан іздейді. **SoundCloud** таңдасаңыз, бірден сол қызметтен іздейді; **YouTube** таңдасаңыз, тек YouTube қолданылады. `yt-dlp` тек ән метадеректерін іздейді, ойнату әр қызметтің ресми плеерінде жүреді. Пауза, жалғастыру, дыбыс және автоматты плейлист екі қызметте де жұмыс істейді. Бұрынғы YouTube тыңдалымдары жаңарту кезінде сақталады. Автоматты ойнату бұғатталса, Play басыңыз. Каталогта әннің басқа орындалуы, ремиксі немесе қысқа нұсқасы болуы мүмкін; дұрыс орындаушыны нәтижеден таңдаңыз. Кез келген әннің тегін әрі толық қолжетімді болатынына кепілдік жоқ. Тікелей YouTube сілтемесінің атауы белгісіз болса, басқа қызметтен табу үшін ән атауын жазыңыз.

**Аниме** бетінде атауды, қажет болса маусым мен серияны жазыңыз. `Гачиакута` атауының кейбір қате жазылымдары да танылады. Аян сайттың HTML бетінде берілген жеке iframe плеерін немесе MP4/WebM бейнесін табады және тек соны көрсетеді. Толық сайт, мәзірі және іздеу беті қолданбаға жүктелмейді. Бірнеше плеер табылса, керегін таңдауға болады. Серияға тікелей сілтеме табылса, сол серияның плеері ашылады; табылмаса, серияны плеердің өзінен таңдау қажет болуы мүмкін. JavaScript арқылы ғана жасалатын немесе танылмаған плеер болса, Аян «Жеке бейнеплеер табылмады» деп көрсетеді. Қызметтің брендін немесе өз плееріндегі жарнамасын қолданба өшірмейді. Сыртқы сайтты тек **Сайтта ашу** сілтемесін өзіңіз басқанда аша аласыз.

**Жиі тыңдайтын әуендеріңіз** плейлисті бастапқыда бос болады. YouTube ойнатқышында әнді кемінде 30 секунд нақты тыңдасаңыз, сол ойнату сеансына бір тыңдалым есептеледі. Бір сеанста пауза жасап, жалғастыру қайта санамайды; жаңа қайта ойнату жаңа сеанс болады. Әндер тыңдалым жиілігіне, одан кейін соңғы белсенділікке қарай реттеледі. **Плейлистті тыңдау** арқылы тізімді бастаңыз, **Келесі ән** арқылы ауыстырыңыз. Плейлист SQLite базасында сақталады; алдын ала ойдан қосылған сүйікті әндер жоқ.

Еске салу қолданба немесе оның беті ашық тұрған кезде көрсетіледі. Қолданба жабық не компьютер ұйқы режимінде болса, сол сәтте хабарландыру шықпайды; сақталған еске салулар келесі іске қосылғанда көрінеді. Тұрақты Windows фондық қызметі орнатылмайды.

## Қазақша сөзді дәлірек тану және автотүзету

Ollama — мәтіндік көмекші; ол микрофон дыбысын өздігінен танымайды. Қазақша дыбыс үшін қосымша **Whisper** моделі қолданылады. API кілті қажет емес. Бастапқы таңдау — `medium`, бірақ дәлдік акцентке, шуға, микрофонға және ән/аниме атауларына байланысты; 100% тану кепілдігі жоқ.

1. Жаңартылған жобаны ашып, `start-windows.bat` бір рет іске қосыңыз, содан кейін Аянды жабыңыз.
2. `setup-whisper.bat` файлын іске қосыңыз. Ол қосымша кітапханалар мен `medium` моделін (шамамен 1,5 ГБ) жүктеп, модель ашылатынын тексереді. Бірінші орнатуға интернет және жеткілікті дискілік орын/жад керек. Бұрын сәтті орнатылған модель қайта жүктелмейді.
3. Аянды қайта ашыңыз → **Баптаулар → Дауысты тану және түзету → Тану қызметін тексеру**. «Whisper medium орнатылған» шығуы керек. Нақты модель жадқа бірінші тану кезінде жүктеледі, сондықтан алғашқы жауап баяу болуы мүмкін.
4. Пәрмен тілін **Қазақша** таңдаңыз. Микрофоннан кейін «Айтыңыз» белгісін күтіп сөйлеңіз. Пәрмен ұзақтығы 20 секундқа дейін; сөйлем ішіндегі шамамен 1,2 секунд үзіліске рұқсат беріледі.
5. Әдепкіде танылған мәтін орындауға дейін көрсетіледі. Оны өңдеп, **Мәтінді орындау** басыңыз. **Бастапқы мәтінді қою** Ollama ұсынған өзгерісті кері қайтарады; **Бас тарту** пәрменді орындамайды. Тексеру кезінде «Аян» шақыруы уақытша тоқтайды.

**Ollama арқылы түзету ұсыну** баптауын қосып сақтасаңыз, орнатылған жергілікті мәтін моделі танылған сөздерді түзетуге тырысады. Өзгерткен мәтіні әрқашан тексеруге беріледі: модель мағынаны не ән атауын қате өзгертуі мүмкін. Ollama жоқ, баяу немесе жарамсыз жауап берсе, танылған мәтін жоғалмайды. Ақылы сервиске автоматты ауысу жоқ. Түзету дауыстан келген мәтінге ғана қолданылады.

**Жеке түзету сөздігіне** жиі қате танылатын атауларды қосыңыз, мысалы:

```text
молдан азар => Moldanazar
гачи акута => Гачиакута
```

Тек енгізілген толық сөз/сөз тіркестері ауыстырылады. Қолсыз басқару үшін **Орындамас бұрын танылған мәтінді көрсету** және **Ollama арқылы түзету ұсыну** белгілерін өшіріңіз; жеке сөздік қолданыла береді.

Баяу компьютер үшін жоба қалтасындағы PowerShell-де `./setup-whisper.bat small` орындауға болады (шамамен 0,5 ГБ). Көбірек жад пен уақыт жұмсауға дайын болсаңыз, `./setup-whisper.bat large-v3` (шамамен 3 ГБ) таңдаңыз. Орнатқыш сәтті аяқталған соң таңдалған модельді баптауға сақтайды; Аян сол кезде жабық болуы керек. `medium`/`large-v3` CPU-да елеулі уақыт алуы мүмкін. Баптауда модель атауын ауыстыру өздігінен жүктеуді бастамайды.

Модельдер `%LOCALAPPDATA%\Ayan\models` ішінде сақталады (`AYAN_DATA_DIR` берілсе, сол қалтада). Whisper осы бастапқы кодпен Windows іске қосқышында қолданылады. `.exe` жинау керек болса, алдымен `setup-whisper.bat`, содан кейін `scripts/build-windows.ps1` орындаңыз; бұрын жиналған `.exe`-ге Python кітапханасын орнату жеткіліксіз. Браузердегі микрофон браузердің өз тану қызметін қолданады, бірақ мәтінді түзету мен тексеру екеуінде де жұмыс істейді.

Шуды азайту үшін құлаққап қолданыңыз немесе музыка дыбысын бәсеңдетіңіз. Windows-та **Steam Streaming Microphone** орнына нақты **Набор микрофонов — Realtek(R) Audio** не өз гарнитураңызды әдепкі кіріс ретінде таңдаңыз.

## Микрофон дауысты қабылдамаса

**«Дауыс естілмеді»** — бағдарлама күту уақыты ішінде сөйлеудің басталуын анықтай алмады. Бұл кезеңде аудио әлі Google-ға жіберілген жоқ.

1. **Windows → Параметры → Система → Звук → Ввод** бөлімінде сөйлейтін микрофонды таңдаңыз. Микрофонды тексеру кезінде сөйлегенде кіріс индикаторы қозғалуы керек. Қозғалмаса, құрылғының mute батырмасын, қосылуын және кіріс дыбыс деңгейін тексеріңіз.
2. Бірнеше құрылғы болса, **Win+R → `mmsys.cpl` → Запись** ашыңыз. Қажетті микрофонды оң жақ батырмамен басып, **Использовать по умолчанию** таңдаңыз. Аян осы әдепкі кіріс құрылғысын қолданады.
3. **Windows 11: Параметры → Конфиденциальность и безопасность → Микрофон**. **Доступ к микрофону**, **Разрешить приложениям доступ к микрофону**, **Разрешить классическим приложениям доступ к микрофону** қосулы болсын. Windows 10-да осы баптаулар **Параметры → Конфиденциальность → Микрофон** ішінде.
4. Аянды жауып, `start-windows.bat` арқылы қайта іске қосыңыз. Микрофонды басқанда шуды өлшеу аяқталғанша үнсіз күтіңіз; **«Айтыңыз, тыңдап тұрмын…»** шыққаннан кейін ғана айтыңыз.
5. Аяндағы тіл айтатын сөзіңізге сәйкес болсын: қазақша үшін **Қазақша → «Көмек»**, орысша үшін **Русский → «Помощь»**.

**«Сөзді түсіне алмадым»** шықса, аудио жазылды, бірақ тану қызметі сөзді ажырата алмады: тілді, сөйлеу анықтығын және шуды тексеріңіз. **Сөйлеуді тану сервисіне қосыла алмадым** деген хабар интернет/қызмет кезеңіне қатысты. Бағдарлама Windows desktop режимінде PyAudio пайдаланады, сондықтан Chrome сайтына микрофон рұқсатын беру бұл режимнің баптауын алмастырмайды.

## Деректер және диагностика

Windows қолданбасы деректерді `%LOCALAPPDATA%\Ayan` қалтасында сақтайды:

- `ayan.sqlite3` — күнделік және еске салулар;
- `preferences.json` — баптаулар және Windows DPAPI арқылы қорғалған API кілттері;
- `browsers` — Playwright Chromium;
- `wake-model` — шақыру сөзін жергілікті тануға арналған Vosk моделі;
- `desktop.log` — іске қосу мен сервер журналы.

Қолданба жаңартылғанда осы қалта сақталады. Өзге сақтау қалтасын `AYAN_DATA_DIR` арқылы көрсетуге болады; браузерлер орны үшін `PLAYWRIGHT_BROWSERS_PATH`, дайын Chromium executable жолы үшін `AYAN_CHROMIUM_EXECUTABLE` қолданылады. Сервер тек `127.0.0.1` адресінде тыңдайды және әдепкіде бос портты таңдайды. Тұрақты порт қажет болса, launcher-ге `--port 8765` немесе PowerShell скриптіне `-Port 8765` беріңіз.

## Әзірлеу және тексеру

Linux/macOS ортасында native Windows терезесінің орнына жергілікті web интерфейсін іске қосыңыз. Python 3.12 ұсынылады:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Браузерде `http://127.0.0.1:8000` ашыңыз. Бұл режимде деректер әдепкіде жобаның `data` қалтасында сақталады. Linux жүйесінде Chromium-ның жүйелік кітапханалары жетіспесе, Playwright-тың [ресми нұсқаулығына](https://playwright.dev/python/docs/browsers#install-system-dependencies) сай орнатыңыз. Бұлт ортасында жүйелік `/usr/bin/chromium` болса, ол жүктелген Playwright браузері болмаған кезде қолданылады.

```bash
python -m pytest
AYAN_DATA_DIR=/tmp/ayan-check python desktop.py --check
```

Тесттер командаларды, деректерді сақтау мен API әрекеттерін тексереді. Дауыс құрылғысы, YouTube желілік қолжетімділігі және native Windows терезесі жеке тексеріледі. Бұлт ортасындағы YouTube сұрауы желілік 403 шектеуіне ұшырауы мүмкін; оқшауланған API және ойнатқыш тесттері нақты YouTube дыбысының ойналғанын растамайды. Chromium жүктеу доменіне қолжетімділік шектелген ортада алдын ала орнатылған браузерді `AYAN_CHROMIUM_EXECUTABLE` арқылы таңдаңыз; TLS тексеруін өшіру қажет емес.

Орындалған тексерулер мен қалған шектеулер [VALIDATION.md](docs/VALIDATION.md) файлында жазылған.

`AYAN_PROXY_DNS=1` параметрі DNS-ті өзі шешетін, алдын ала конфигурацияланған сенімді `HTTPS_PROXY` проксиі бар бұлт ортасына ғана арналған. Әдепкі режимде, соның ішінде Windows қолданбасында, браузер сайт адресін жергілікті DNS арқылы тексеріп, ішкі желі мекенжайларын бұғаттайды.

# Тексеру нәтижелері

Бұл нұсқа Linux бұлт ортасында Python 3.12 және жүйелік Chromium арқылы тексерілді.

- `.venv/bin/python -m pytest -q`: **499 тест өтті**. Музыка пәрмендері, дыбыс деңгейі, күнделік, апталық тапсырмалар, еске салулар, API және баптаулар тексерілді. Екі ескерту Python 3.13-те жойылатын `aifc` пен `audioop` модульдеріне қатысты.
- `node --check app/static/app.js`, Python модульдерін компиляциялау және `pip check` өтті.
- `AYAN_DATA_DIR=/tmp/ayan-check-removal .venv/bin/python desktop.py --check`: жергілікті сервер ашылып, интерфейс жүктеліп, процесс дұрыс тоқтады.
- Нақты Chromium-дағы оқшауланған интерфейс сынағында аниме мен браузер мәзірлері жоқ екені, музыка пәрменінің жауабы дауысталмағаны және микрофоннан берілген «дауысын көтер» пәрмені ойнатқышты 60%-дан 70%-ға өзгерткені тексерілді. JavaScript қатесі болған жоқ. Бұл сынақта дауыс тану, YouTube плеері және API жауаптары алмастырылды.
- Жойылған аниме және сайт басқару API жолдары 404 қайтаратыны тексерілді. Көмекшінің әрекеттер тізімінде бұл пәрмендер жоқ.

Бұл ортада нақты Windows микрофоны, WebView2 терезесі, YouTube/SoundCloud дыбысы және дайын `.exe` іске қосылған жоқ. Windows-та жаңартылған қолданбаны ашып, өз микрофоныңызбен пәрмен беріп және нақты әннің дыбысын тексеріңіз. GitHub ZIP архивінде бастапқы код бар; оны `start-windows.bat` арқылы іске қосуға болады.

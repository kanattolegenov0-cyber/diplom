Аянды жабыңыз да, жоба қалтасындағы setup-whisper.bat файлын іске қосыңыз. Ол small моделін орнатады. Қайта ашқан соң күйін тексеріңіз. API кілті керек емес; орнатылған Whisper дыбысты компьютерде өңдейді. Бұл таңдау Windows қолданбасына арналған; браузер өз тану қызметін қолданады.

Алдымен баптауларды сақтаңыз.

Растау өшірулі болса, Ollama түзеткен мәтін бірден іздеуге немесе пәрменді орындауға жіберіледі. Түзету қызметі дайын болмаса, бастапқы танылған мәтін қолданылады. Қолмен тексеру үшін растауды қосыңыз.

Әр жол: қате сөз => дұрыс сөз. Тек өзіңіз қосқан сөздер ауыстырылады; 50 жұпқа дейін. Дауыс мәтініне ғана қолданылады.
Ақылды көмекші

Сұраққа жауап береді, бірнеше істі кезекпен орындайды. Негізгі пәрмендер AI қызметінсіз де жұмыс істейді.

Орнатылған модельді таңдаңыз немесе модель атауын жазыңыз. Жаңа таңдауды алдымен сақтаңыз.
Ollama күйі тексерілуде…

Ollama-ны ресми сайттан орнатыңыз ↗, іске қосыңыз. Содан кейін терминалда модельді жүктеңіз:

ollama pull qwen2.5:3b

Жүктеу біткен соң «Қайта тексеру» батырмасын басыңыз. API кілті қажет емес. Алғашқы жауап модель жүктелгенше бірнеше минут күтуі мүмкін.

Ollama сөйлесуді осы компьютерде өңдейді. Модельді бастапқы жүктеуге интернет керек. YouTube, Google дауыс тану және желілік дауыстау интернетті қолданады. Жауап сапасы модель мен компьютерге байланысты.

Бос қалдырсаңыз, сақталған кілт өзгермейді.

OpenAI сұрағына мәтініңіз бен сөйлесудің соңғы 8 хабары жіберіледі. Интернет пен ақылы API балансы қажет болуы мүмкін. Ollama үшін бұл кілт керек емес.

Көмекшінің дауысы
Байсалды мәнер: Дәулет, сәл баяу әрі төмен үн. Нақты актердің дауысына еліктемейді.
Дайын қазақша дауыстар. Сапасы таңдалған қызметке байланысты; интернет керек.
Бос қалдырсаңыз, сақталған кілт өзгермейді.

Лицензияланған немесе бөлісілген дауысты таңдаңыз. Нақты актердің дауысы автоматты түрде қосылмайды. Қызмет ақысы және қазақша айтылуы таңдалған дауысқа байланысты.

Қазақша жауап үшін компьютерде қазақша дауыс болуы керек. Басқа тілдің дауысына автоматты ауыспайды.

Дауыстауға жауап мәтіні таңдалған қызметке жіберіледі. Дауыс шықпаса, жауап мәтін түрінде сақталады.

Алдымен өзгертулерді сақтаңыз.
«Аян» деп шақыру

«Аян» сөзі компьютердегі жергілікті модельмен танылады. Шақырғаннан кейінгі пәрмен таңдалған дауыс тану қызметімен өңделеді: Whisper — компьютерде, Google — интернет арқылы. Whisper орнатылса, «Аян» сөзімен бірге айтылған пәрменді де жергілікті қайта таниды. AI мен дауыстау таңдалған қызметтерін қолданады. Қарапайым әңгіме пәрмен ретінде орындалмайды.

Микрофон мен жергілікті шақыру моделі қажет. Браузер нұсқасында тұрақты тыңдау қосылмайды. Аян жауап бергенде, шақыру уақытша үзіледі.
